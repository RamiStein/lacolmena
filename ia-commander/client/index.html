¿Cómo agregar nuevas acciones lentamente?

El sistema cuenta con un Action Registry auto-descubrible. Para sumar una nueva acción (ej: Spotify, Calendario, Notion, Telegram), solo creas un archivo en server/actions/:

// server/actions/spotify.action.js
import { BaseAction } from '../registry/BaseAction.js';

export default class SpotifyAction extends BaseAction {
  constructor() {
    super({
      id: 'play_music',
      name: 'Reproducir música',
      description: 'Reproduce una canción o playlist en Spotify.',
      parameters: {
        type: 'object',
        properties: {
          track: { type: 'string', description: 'Nombre de la canción o artista' }
        },
        required: ['track']
      }
    });
  }

  async execute(params) {
    // Tu lógica concreta aquí (API de Spotify, protocolo spotify:search:..., etc.)
    return { success: true, message: `Reproduciendo ${params.track}` };
  }
}

¡Y listo! Al reiniciar el servidor o guardar el archivo, la IA aprende a usarla inmediatamente.
