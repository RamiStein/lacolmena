¿Cómo se agregan más acciones?

El sistema cuenta con un Action Registry modular. Cada acción define sus parámetros (destinatario, texto, hora, etc.) y su ejecutor.

// Ejemplo: Agregar acción de Spotify / Calendario
registerAction({
  id: 'play_music',
  name: 'Reproducir música',
  description: 'Abre Spotify con una canción o artista',
  parameters: { track: 'string' },
  execute: (params) => {
    window.location.href = `spotify:search:${params.track}`;
  }
});
